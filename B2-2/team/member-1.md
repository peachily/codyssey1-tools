# 김현중

- 이름: 김현중
- 역할: 팀 소개 문서 및 협업 규칙 담당
- 담당 Issue / PR: [Issue #2](https://github.com/Codyssey2-2/cody2-2Assign/issues/2), [PR #5](https://github.com/Codyssey2-2/cody2-2Assign/pull/5), [Issue #10](https://github.com/Codyssey2-2/cody2-2Assign/issues/10)
- 한마디: 작은 변경도 이슈와 PR로 기록해 팀원이 같은 맥락에서 협업할 수 있게 하겠습니다.

## 협업 목표

- 작업 시작 전 Issue의 완료 조건을 확인하고, 작업 단위마다 `feature/*` 브랜치를 사용합니다.
- PR에는 변경 사항, 변경 이유, 검증 방법을 남겨 리뷰어가 맥락을 빠르게 이해할 수 있게 합니다.
- 충돌이나 실수 커밋을 해결하면 재현 가능한 절차를 협업 문서에 기록합니다.

## PR 전 점검

- [ ] `main` 최신 내용을 반영했고 의도하지 않은 변경이 없습니다.
- [ ] 커밋 메시지에 변경 대상과 결과가 드러납니다.
- [ ] Issue 연결 문구(`Closes #번호`)와 What/Why/How를 PR 본문에 작성했습니다.
