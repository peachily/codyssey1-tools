# 에셋 관리

- `peachily.jpg`: 사용자가 제공한 750×750 복숭아 이미지. Hero와 About에서 동일 경로를 사용합니다. 원본 파일은 수정하지 않았습니다.
- Hero의 중복 이미지는 `alt=""`로 장식 처리하고 About에는 이미지 내용에 맞는 alt를 제공합니다.
- 사진 교체 시 이 파일을 덮어쓰거나 HTML의 두 `src`를 함께 변경합니다. `object-fit: cover`와 정사각형 크기를 유지합니다.
- `icons.svg`: 프로젝트 공통 SVG Sprite. 테마 버튼은 밝은 테마에서 달, 어두운 테마에서 태양을 표시합니다.
