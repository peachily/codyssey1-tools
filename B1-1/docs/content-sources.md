실제 공개 REST 응답으로 대표 저장소 4개를 매칭했습니다. 당시 주 언어는 숫자 몬스터·케이크 만들기 JavaScript, 급식 도구·codyssey1-tools Python입니다. 언어는 API의 저장소 전체 주 언어이며 사용한 모든 기술을 의미하지 않습니다. 웹사이트는 이 값을 동적으로 표시합니다.

Frontend의 HTML/CSS/JavaScript는 본 포트폴리오 구현으로도 확인 가능합니다. Backend & Data는 Node.js/Python만 표시하며 검증되지 않은 DB, AI 기술은 넣지 않았습니다. 기술 숙련도 수치나 경력을 제시하지 않습니다.

수동 데이터는 대표 저장소 선택·순서·한국어 제목·카테고리·설명·검증된 demo URL을 담당합니다. API 응답은 공개 저장소 존재 여부·소유자·주 언어·GitHub 링크를 담당하며 API 오류 때 수동 데이터를 실제 조회 성공처럼 표시하지 않습니다. API는 개인 `/users/peachily/repos`를 페이지별로 조회합니다.
