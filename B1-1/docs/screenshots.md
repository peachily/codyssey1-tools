# 제출용 화면 캡처 — 미완료

2026-10-22 브라우저 연결 시 `No browser is available`, 브라우저 목록 `[]`가 반환되어 실제 렌더링 및 캡처를 수행하지 못했습니다. DOM 자동 테스트는 화면 검증을 대신하지 않습니다. 가짜 화면이나 생성 이미지를 제출용 캡처로 만들지 않았습니다.

320px·768px·1024px에서도 별도 확인하고, 200% 확대 및 키보드 Tab/Shift+Tab/Escape로 조작합니다. 메뉴를 연 모바일 화면도 추가 캡처하면 좋습니다. API 호출 실패 화면, 필터 빈 결과, 폼 오류, reduced-motion도 실제 브라우저에서 재확인합니다.
