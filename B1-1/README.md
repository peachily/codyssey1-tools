# peachily

교육의 경험을 기술로 이어가는 김수정의 개인 포트폴리오.
HTML, CSS, Vanilla JavaScript로 제작하며 빌드 과정과 런타임 의존성이 없습니다.

## 실행

VS Code에서 B1-1/index.html을 Live Server로 열거나 저장소 루트에서
`python3 -m http.server 8000` 실행 후 http://localhost:8000/B1-1/ 접속.
ES Modules 사용으로 file:// 직접 열기는 지원하지 않습니다.

목표 배포 주소: https://peachily.dev (배포 확인 전).
